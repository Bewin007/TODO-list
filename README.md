# ToDo List Application

This project is a basic ToDo list application built with Express and HTML.

## Overview

The application allows users to manage tasks by adding, deleting, and setting reminders for tasks.

### Features

- **Add Task**: Users can add new tasks with a description and optional due date/time.
- **Delete Task**: Remove tasks from the list.
- **Remind Task**: Set reminders for tasks to notify users at specified times.

## Technologies Used

- **Backend**: Express
- **Frontend**: HTML, CSS (styling), JavaScript (client-side interactivity)
